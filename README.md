# Dotfiles

Personal configuration files for macOS.

## Quick start

```bash
git clone https://github.com/Grzelox/dotfiles.git ~/Repositories/dotfiles
cd ~/Repositories/dotfiles
make dry-run       # preview
make install-all   # symlink configs + Homebrew + VS Code extensions + macOS prefs
```

`install.sh` symlinks every config listed in [`configs.txt`](configs.txt) into place, so editing the live file edits the repo. Any existing file is moved to `<file>.backup-<timestamp>` first.

## Make commands

Run `make` to list them.

| Command | What it does |
|---------|--------------|
| `make sync` | Copy everything from this machine into the repo (configs, Brewfile, VS Code extensions, macOS prefs), then show `git status` |
| `make sync-configs` | Only the files in `configs.txt` |
| `make sync-brew` / `sync-vscode` / `sync-macos` | Only that part |
| `make diff` | List configs whose live copy differs from the repo, without changing anything |
| `make status` | `make diff` + `git status` |
| `make install` | Symlink configs into place (`./install.sh`) |
| `make install-all` | Same, plus Homebrew, VS Code extensions and macOS prefs |
| `make dry-run` | Preview `install-all` without changing anything |

Typical update: `make sync`, review `git diff`, commit. Configs that are already symlinked into the repo are skipped by `sync-configs`.

To track a new config, add a line to `configs.txt` (`<repo path> | <path relative to $HOME>`) and run `make sync-configs`.

## install.sh flags

| Flag | What it does |
|------|--------------|
| *(none)* | Symlink all configs (and run `pi/install.sh`) |
| `--dry-run` | Print what would happen, change nothing |
| `--brew` | `brew bundle` from `Brewfile` |
| `--vscode` | Install extensions from `vscode/extensions.txt` |
| `--macos` | `defaults import` the app preferences in `macos/` |
| `--all` | All of the above |

## Neovim

LazyVim configuration: `init.lua`, `lua/config/`, `lua/plugins/` (moonfly, persistence, themer), `lazy-lock.json`, `.neoconf.json`.

## OpenCode

- `opencode.json` -- provider configs (Ollama local, Headroom proxy), MCP servers
- `cli.json` -- rosepine theme, session and diff settings, `herdr-opencode` plugin
- `tui.json`, `tui.jsonc` -- TUI theme and plugin entry
- `herdr-tui-session.js`, `herdr-opencode/tui.js`, `plugins/herdr-agent-state.js` -- herdr integration (generated by herdr; reinstalling the integration overwrites them)
- Not tracked: `bun.lock`, `package.json`, `node_modules/`, `service.json`, backups

## Pi Coding Agent

The `pi/` directory contains configuration for [pi](https://github.com/earendil-works/pi-coding-agent), my AI coding agent. `pi/install.sh` (also called by `./install.sh`) symlinks `settings.json`, `extensions/`, `prompts/` and `skills/` into `~/.pi/agent/`, and never touches the local-only `auth.json` (API keys) or `sessions/`.

### Extensions

| Extension | Purpose |
|-----------|---------|
| `permission-gate.ts` | Confirms before dangerous bash commands |
| `protected-paths.ts` | Blocks writes to `.env`, `.git/`, `node_modules/`, etc. |
| `git-checkpoint.ts` | Stash checkpoints at each turn for `/fork` restore |
| `custom-compaction.ts` | Smarter conversation compaction with summaries |
| `status-line.ts` | Footer status: model, turn count, token usage |
| `plan-mode/` | Read-only plan mode with step tracking |
| `self-improve.ts` | `/pi-status`, `/pi-reload`, `/pi-extensions` commands |
| `commands.ts` | `/commands` -- list all available slash commands |
| `herdr-agent-state.ts` | Reports agent state to herdr panes (generated by herdr) |

### Prompt templates

| Template | Usage |
|----------|-------|
| `/review [file]` | Review staged git changes |
| `/refactor <file>` | Refactor for readability/performance |
| `/debug <error>` | Root cause analysis and fix |
| `/tests <file>` | Generate comprehensive tests |
| `/docs <module>` | Write documentation |
| `/architecture [scope]` | Analyze system design |

## macOS app preferences

Exported with `defaults export` and stripped of machine-specific keys (install IDs, update-check timestamps, window positions, per-display history). Quit the apps before `./install.sh --macos`, then relaunch them.

`make sync-macos` re-exports every domain that has a file in `macos/`. To add an app, export it once and it will be picked up from then on:

```bash
defaults export <bundle id> macos/<bundle id>.plist
```

## Never tracked

This repo is public. These stay local:

- `~/.config/gh/hosts.yml`, `~/.pi/agent/auth.json`, Graphite and Stripe CLI configs (tokens)
- `~/.ssh/` (keys and `config`, which has private hostnames and IPs), `~/.docker/config.json`, `~/.kube/config`
- Zed, spotify_player and Claude Code configs (excluded by choice)
- Raycast (use Raycast's own export), LM Studio, Ollama (large data or models)
